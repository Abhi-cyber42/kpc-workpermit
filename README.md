# KPC Projects Ltd – Online Work Permit System

This is a ready-to-upload React website for KPC Projects Ltd HSE Online Work Permit System.

## Demo Admin Login

Username: admin  
Password: 1234

## Features

- Online permit submission
- Auto permit number
- HSE approval workflow
- Admin approve / reject / close
- Digital signature fields
- QR approval text
- CSV download
- PDF / print permit
- Email notification
- Permit dashboard
- KPC logo integration
- Records saved in browser local storage

## How to run on computer

1. Install Node.js from https://nodejs.org
2. Open this folder in Terminal / Command Prompt
3. Run:

```bash
npm install
npm run dev
```

4. Open the link shown in the terminal.

## Upload to GitHub

```bash
git init
git add .
git commit -m "KPC Work Permit System"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/kpc-workpermit.git
git push -u origin main
```

## Deploy on Vercel

1. Login to https://vercel.com
2. Click Add New Project
3. Import your GitHub repository
4. Click Deploy

Suggested live URL:

https://kpc-workpermit.vercel.app
